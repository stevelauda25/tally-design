## 2026-07-21 — Tally token + atom collection

### Foundations

- Color, typography, spacing, radius, and elevation tokens collected from tally-ui-source. This collection is this repo's token source; see the Foundations pages for the full scales and decision log.

### Components

- 15 atoms documented from the Tally apps: Button, Badge, Checkbox, Switch, Tag, Input, Text Area, Radio, Segmented Button, Slider, Loading Spinner, Avatar, Separator, List Base, Tooltip.
